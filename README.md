## Notes on what changed
- Files were grouped by **concept**, not by the random project name you gave
  each VS Code project (e.g. "Animal life", "Emplyee", "Car2").
- `demo21.java` was renamed to `Demo21.java` to match the capitalization of
  every other Demo file.
- The `package ...;` line at the top of some files was removed, since each
  topic now lives in its own folder — keeping the package statement would
  have broken compilation after the move.
- The auto-generated `.vscode/`, `lib/`, `bin/`, and boilerplate `README.md`
  files from each old project folder were dropped — they were identical
  placeholders and not useful for reviewing code. If you want a runnable
  VS Code Java project again, just open a topic folder as your workspace
  and VS Code will regenerate what it needs.
